Where this screen appears

During onboarding, after a user enters their phone number for account verification, Amoraea presents a clearly labeled, unchecked consent checkbox alongside the full disclosure text shown at left.

  1. User enters their mobile number during signup.
  2. The consent checkbox is displayed unchecked — nothing is pre-selected on the user's behalf.
  3. The user must actively tap the checkbox to opt in before continuing.
  4. Declining the checkbox does not block account creation — SMS consent is never required to use the app.
  5. Users can revisit and change this preference anytime from Settings > Notifications.
